# 主動式 ETF 跟單雷達

這是一個靜態版台灣主動式 ETF 持股監控頁面。

## 資料來源

目前靜態快照來源為 ETF資訊網（整理自公開頁面）：https://www.etfinfo.tw/active

公開網站不會即時爬資料，只會讀取 `data/snapshots.json`。要更新資料時，請在本機執行更新腳本產生新的 `data/snapshots.json`，再推上 GitHub。

## 主要功能

- 每日成分股快照
- 持股異動偵測
- 跨 ETF 持股重疊
- 個股被持有追蹤
- 多家同步加碼
- 新增雷達與賣出雷達

## 台股顏色習慣

本頁已依台股習慣設定：漲、加碼、新增為紅色；跌、減碼、清空為綠色。
